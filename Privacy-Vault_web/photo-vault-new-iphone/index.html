Photo Vault: Secure Folder

How to Move Photo Vault to a New iPhone

Photo Vault: Secure Folder uses local vault storage. Your private photos, videos, PDFs, and documents do not automatically appear on a new iPhone. The safe migration path is to create and verify an encrypted ZIP backup before you erase or replace the old device.

App overview Backup and restore Support

Before changing iPhones

  1. Open Photo Vault: Secure Folder on the old iPhone and unlock the main vault.
  2. Go to Settings > Data Management > Export Backup and create an encrypted ZIP.
  3. Save the ZIP to Files, iCloud Drive, a Mac, a PC, or an external drive that you control.
  4. Restore the ZIP on the old iPhone or another test location and open several representative files.

Keep the old iPhone and its original vault untouched until the backup has passed this test.

Restore on the new iPhone

  1. Install Photo Vault: Secure Folder from the App Store on the new iPhone.
  2. Open the app and complete the initial setup with a main PIN.
  3. Open Settings > Data Management > Restore from Backup.
  4. Select the encrypted ZIP from Files or the storage location where you saved it.
  5. Enter the backup password and wait for the restore to finish.
  6. Check several photos, videos, PDFs, and documents before removing the old app or device.

Does it sync automatically through iCloud?

No. The vault is local-only and the app does not operate a cloud vault or sync vault media to its servers. A new iPhone needs the encrypted ZIP backup that you exported and moved yourself.

This approach keeps the recovery file under your control, but it also means that losing the iPhone before making a backup can mean losing local-only vault content.

What if I forgot the PIN?

The app team cannot recover a forgotten main PIN or bypass the encryption protecting local vault content. Keep the main PIN and backup password in a secure password manager or another safe location.

If you still have access to the old iPhone, export and verify the backup before making any device change. If you no longer have access and no verified backup exists, recovery may not be possible.

Migration checklist

  • Exported an encrypted ZIP from the old iPhone.
  • Saved a primary and secondary copy in places you control.
  • Verified that the backup password works.
  • Restored and opened representative files on the new iPhone.
  • Only then deleted the old vault or reset the old device.
