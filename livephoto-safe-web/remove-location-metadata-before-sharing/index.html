Metadata privacy guide

Remove location metadata before the file leaves your phone

A normal-looking photo can carry coordinates, capture time, device, and camera information that the pixels do not show.

Why “the platform strips it” is incomplete

A service may remove metadata from a public version, but the original file must first be handed to that service. Preparing a clean copy locally gives you control before upload.

What the protected copy changes

LivePhoto Safe rebuilds output from decoded media and does not copy the source metadata wholesale. It removes source location and privacy-sensitive shooting metadata while retaining only the limited information needed for a valid protected output.

Check visible clues too

Metadata removal cannot hide a street sign, house number, reflection, school logo, landmark, or document visible in the image. Review detected regions and the full motion before sharing.

Useful scenarios

  • Posting a vehicle or household item to a marketplace
  • Sharing photos taken at home or a private event
  • Sending family photos to a broad group
  • Uploading media to a service with unclear metadata handling
