Reply properly, even away from your desk

A practical workflow for repeat customer questions and sales enquiries.

The short answer

For repeated questions on your iPhone, save your own replies as named snippets. In a text field that supports custom keyboards, select the saved reply, check it and send it yourself. Use a configured Pro template when some details change.

When a quick acknowledgement is not enough

A customer asks about availability while you are away from your desk. You know the answer, but writing the whole explanation on your phone is another task. A saved reply keeps your wording ready without turning the conversation into an automatic response.

Start with questions you actually receive

Create a small library around repeat questions, rather than collecting dozens of generic scripts. Useful categories might be Availability, Booking and Follow-up. Give each snippet a name that explains when to use it.

EXAMPLE TEXT · EDIT TO MATCH YOUR BUSINESS

“Thanks for getting in touch. Please send the service you need and your preferred date, and I’ll confirm availability.”

This kind of reply asks for the next useful detail. A saved booking URL can be a separate snippet, so you can use it only when relevant. Links are inserted as plain text URLs; rich-text link titles and attachments are outside this workflow.

A repeatable saved-reply workflow

  1. Write and save the reply in the main app, using wording you would actually send.
  2. Enable Quick Content under iOS Settings → General → Keyboard → Keyboards → Add New Keyboard.
  3. In a supported message or email text field, use the globe key to switch to Quick Content.
  4. Find the relevant category and tap the reply to insert it.
  5. Read the result, personalize it if needed using your usual keyboard, and send it yourself.

When the same message needs different details

Pro templates can reuse fixed information and configured options. Set up fields under Settings → Template Details in the main app, then add the matching fields to your template. In the keyboard, choose the available options, adjust a supported date if needed, and preview the complete message before inserting.

A package reply might have Standard and Express as saved choices. New free-text template values must be prepared in the app; the keyboard selects configured values.

Know where this fits

Quick Content is for manually reusing text. It does not automate replies, track customer conversations or send campaigns. Password fields and some apps do not support third-party keyboards. Check it in the text fields you use before relying on the workflow. No Full Access is required.

Why this guide focuses on mobile replies

In a public Outlook user discussion, someone described receiving sales messages while out and wanting to send a properly worded response from a phone. This is a qualitative user signal, not a Quick Content review or a guarantee of compatibility with Outlook.
