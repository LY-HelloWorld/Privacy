Technical Support

Help with Quick Content Keyboard for iOS.

Email luoyi9932@gmail.com for technical support, purchase questions, or feedback.

Enable the keyboard

  1. Open Quick Content Keyboard and save a snippet.
  2. Open iOS Settings → General → Keyboard → Keyboards → Add New Keyboard, then select Quick Content Keyboard. Its name may be localized.
  3. Open an app with a text field. Touch and hold the globe key and select Quick Content Keyboard.
  4. Select a snippet to insert its text. For templates, complete the available selections and review the preview before inserting.

Full Access is not required. iOS uses the system keyboard for secure password fields, and some apps disable third-party keyboards.

The keyboard is missing or content is out of date

Check that the keyboard is enabled in iOS Settings. Open the main app and confirm that your changes are saved, then switch away from the keyboard and select it again. If the issue occurs in only one app, try another ordinary text field.

Set up template details

In the main app, open Settings → Template Details. Add fixed values such as your name or signature, or add a list of options to select when using a template. Insert the matching field in the snippet editor. If a template reports missing configuration, complete the field in the main app and try again.

The keyboard uses configured values and selections; it does not show a free-text template editor. You can cancel the preview before inserting.

Restore a Pro purchase

Open the Pro screen from Settings and choose Restore Purchases. Use the Apple Account that made the original purchase. If restoration fails, check your connection and try again. Contact us with the error message if the problem continues.

Back up or move your content

With Pro, use the JSON export and import options in the main app. Keep a copy of your exported file somewhere you can access later. An exported file contains your saved text and template details, so review it before sharing. The app does not provide a cloud account or developer-operated backup service.

Identity checks

Protected snippets use system authentication, such as Face ID, Touch ID, or your device passcode. Follow the system prompt and check your device authentication settings if verification fails. This feature controls access in the interface; it does not encrypt the stored snippet data.

Send a useful issue report

Please include your iOS version, app version, what you were doing, and the steps to reproduce the issue. For keyboard problems, include the name of the app where it happened. Screenshots can help; remove private snippet text and personal information before sending them.
