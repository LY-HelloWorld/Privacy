FAQ

A few things you might be wondering.

Does it work in every app?

It works in text fields that allow third-party keyboards. Password fields and some apps use the system keyboard or disable custom keyboards. Send behavior also depends on the host app.

Do I need to allow Full Access?

No. Saved snippets stay on your device, and the keyboard does not request Full Access.

Does it automatically reply or bulk-send messages?

The workflow is to reuse text you saved. You select it, check the inserted message and decide when to send. It does not provide an automatic-reply or bulk-messaging workflow.

Where do I set up template choices?

With Pro, configure fixed values and options under Settings → Template Details in the main app, then insert the matching fields in your snippet. The keyboard selects configured details and previews the result. Missing fields must be configured in the main app.

What is included for free?

Free supports 3 snippets and 1 category. One-time Pro unlocks unlimited snippets and categories, template variables, device authentication and JSON import/export. There is no subscription.

Can I sync between devices?

There is no automatic cloud sync. Pro supports manual JSON export/import including snippets and template details. You are responsible for keeping exported files.

How does it differ from iPhone Text Replacement?

Text Replacement fits a few shortcuts you remember and type. Quick Content lets you organize, search and pin in the main app, then tap saved entries in the keyboard. Pro adds configured template choices. See the comparison guide below.

Which interface languages are supported?

The app and keyboard support English, Simplified and Traditional Chinese, Japanese, Korean, French, German, Spanish and Brazilian Portuguese. Your saved text is not automatically translated.
